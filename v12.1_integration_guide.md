## 1. ActionCards — Today Page

Replace the existing "quick actions" section in `src/app/today/page.tsx`:

```tsx
// At top of today/page.tsx
import ActionCards from "@/components/ActionCards";

// Replace the old cc-tile grid with:
<ActionCards />
```

Result: 4 colored gradient cards — New Note (purple), New Task (amber), Focus Timer (teal), Learning (pink) — exactly like Image 1.

## 2. NoteCard — Notes Page

In `src/app/notes/page.tsx`, replace the note list items:

```tsx
import NoteCard from "@/components/NoteCard";

// Inside your notes.map():
<NoteCard
  key={note.id}
  emoji="✨"
  title={note.title}
  snippet={note.content?.slice(0, 100) + "..."}
  date={format(new Date(note.created_at), "MMM d, yyyy")}
  tags={[{ label: "🔴 High Priority", variant: "priority" }]}
  tint="purple"   // "purple" | "teal" | "amber" | "none"
  onClick={() => openNote(note)}
/>
```

## 3. ProductivityGoalCard — Today or Analytics Page

In `src/app/today/page.tsx`, place this after the ActionCards:

```tsx
import ProductivityGoalCard from "@/components/ProductivityGoalCard";

// Use real data from your Supabase hooks:
<ProductivityGoalCard
  weeklyDone={todayDone.length}
  weeklyTotal={todos.filter(t => !t.deleted_at).length}
  focusMinutes={todayFocusMinutes}
  dailyBars={[
    { label: "Sat", count: 10, color: "#ec4899" },
    { label: "Sun", count: 9,  color: "#3b82f6" },
    { label: "Mon", count: 6,  color: "#f59e0b" },
    { label: "Tue", count: 5,  color: "#7c6ffd" },
    { label: "Wed", count: 0,  color: "rgba(255,255,255,0.15)" },
    { label: "Thu", count: 0,  color: "rgba(255,255,255,0.15)" },
    { label: "Fri", count: 0,  color: "rgba(255,255,255,0.15)" },
  ]}
/>
```

To get real weekly data, add a `fetchWeeklyTaskCounts()` function in `supabase.ts` that queries `activity_log` grouped by `created_at::date`.

## 4. CalendarWeekStrip — Calendar Page

In `src/app/calendar/page.tsx`, replace the date navigation:

```tsx
import CalendarWeekStrip from "@/components/CalendarWeekStrip";

const [selectedDate, setSelectedDate] = useState(new Date());

// Replace existing date navigation:
<CalendarWeekStrip
  selectedDate={selectedDate}
  onSelectDate={setSelectedDate}
/>
```

## 5. CSS Additions — globals.css

Copy everything from `globals_v12.1_additions.css` and paste at the **bottom** of `src/app/globals.css`.

These classes let you use the new design tokens directly in JSX via `className`:
- `.action-card-link.ac-purple` etc.
- `.note-card-purple` / `.note-card-teal` / `.note-card-amber`
- `.seg-tabs` + `.seg-tab.active`
- `.browse-row` + `.browse-item` + `.browse-icon-purple` etc.
- `.cal-event.cal-event-pink` etc.
- `.notif-item` + `.notif-icon-bubble.notif-icon-purple` etc.

## Summary of Visual Changes

| Screen | Before | After (v12.1) |
|---|---|---|
| Today | Tiny cc-tile grid | 4 large gradient action cards + stats row |
| Notes | Plain list | Colored tint cards with emoji + tag chips |
| Analytics | Bar chart only | Weekly goal card + day activity bars |
| Calendar | Table/grid nav | Horizontal pill week strip + colored event cards |
| Notebooks | Text list | Icon tile cards with colored backgrounds |

## No Supabase Changes Required
All components use existing data from:
- `todos` table
- `focus_sessions` table  
- `activity_log` table (already used in Analytics)
- `daily_habits` / `habit_log`
